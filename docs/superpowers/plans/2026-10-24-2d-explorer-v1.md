# mat2vec-2d-explorer v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone Streamlit dashboard. It ranks MC2D 2D semiconductors against a chosen property or deposition method using pretrained Mat2vec embeddings, maps them in a 2D/3D PCA view, and evaluates what the embeddings capture and where they fail.

**Architecture:**
- An offline build script loads the 800 MB pretrained model once.
- It pulls MC2D band gaps over OPTIMADE.
- It writes small artifacts: parquet, npz, json.
- A numpy-only `ranking.py` holds every scoring and evaluation function.
- `app.py` reads the artifacts and calls `ranking.py`.
- Formula normalization is copied in from mat2vec (MIT) with attribution.

**Tech Stack:**
- Python 3.11.
- Runtime: streamlit, pandas, numpy, plotly, pyarrow.
- Build: gensim ≥4.3,<5, pymatgen, requests. PCA is computed with numpy SVD, so there is no scikit-learn or UMAP.
- Tests: pytest.

**Spec:** `docs/superpowers/specs/2026-10-24-2d-explorer-design.md`

## Global Constraints

- Repo root: `mat2vec-2d-explorer/`. The original `mat2vec` checkout next to it (`../mat2vec`) must stay unchanged (`git status` shows nothing new from us).
- Conda env `mat2vec-explorer`, Python 3.11.
- Runtime deps go only in `requirements.txt`: streamlit, pandas, numpy, plotly, pyarrow. Build deps go only in `requirements-build.txt`: gensim>=4.3,<5, pymatgen, requests, pytest.
- All ranking uses the full 200-d vectors. PCA coordinates are for display only. PCA is computed at build time and saved in the artifacts.
- `ranking.py` imports only numpy and pandas. No scipy or sklearn at runtime.
- Model dir comes from env var `MAT2VEC_MODEL_DIR`, default `../mat2vec/mat2vec/training/models`.
- MC2D source: `https://optimade.materialscloud.org/main/mc2d/v1/structures`. Keep `_mcloud_band_gap > 0`. Raw cache at `data/mc2d_raw.json` (git-ignored).
- Scores:
  - `out_in` = normalized output vector of the material · normalized input vector of the target.
  - `in_in` = cosine of the two input vectors.
- Low-count badge threshold: `LOW_COUNT = 20`. Context words: `k = 10`. Vocabulary table: the 50,000 most frequent tokens plus all candidates.
- Caveat copy, verbatim, shown under every ranking table: **"Literature association before 2018, not feasibility."**
- No stability column anywhere.
- `artifacts/` is git-ignored and never committed. The pretrained weights' redistribution permission is unverified.
- No GitHub repo creation, push or deploy.
- Work happens on branch `v1` in the new repo. `main` holds only the docs commit.

## Review Focus

1. **Typed target is a formula or has capitals** (e.g. `MoS2`, `Thermoelectric`). Try the exact token first, then lowercase, then `_`-joined lowercase. → test in Task 2.
2. **Typed target is not in the vocabulary, or is empty.** Show a friendly message and no traceback. → tests in Tasks 2 and 4.
3. **App started before the build ran.** Show `st.error` with the exact build command. → test in Task 4.
4. **Zero-norm vector** (padding or degenerate token). Normalizing must not produce NaN. → test in Task 2.
5. **Known-CVD list entry missing from the candidates.** Exclude it from the metrics and show the excluded count; never crash. → test in Task 2.

### Task 2: Ranking and evaluation core (numpy only)

**Files:**
- Create: `explorer/ranking.py`, `tests/test_ranking.py`

**Interfaces:**
- Produces (all in `explorer/ranking.py`):
  - `unit(X: np.ndarray) -> np.ndarray`: row-wise L2 normalization. Zero rows stay zero, no NaN.
  - `score(cand: np.ndarray, target: np.ndarray) -> np.ndarray`: `unit(cand) @ unit(target)`. Used for both modes: pass input vectors for `in_in`, output vectors for `out_in`.
  - `ranks(scores: np.ndarray) -> np.ndarray`: 1-based; rank 1 = highest score.
  - `resolve_target(text: str, token_index: dict[str, int]) -> str | None`: try `text.strip()`, then `.lower()`, then lowercase with whitespace runs replaced by `_`. Return `None` for empty or unknown input.
  - `context_words(mat_out: np.ndarray, vocab_in: np.ndarray, vocab_tokens: list[str], target_in: np.ndarray, k: int = 10) -> pd.DataFrame`. Columns are `token`, `assoc`, `target_cos`. `assoc = unit(vocab_in) @ unit(mat_out)`; take the top k by `assoc`.
  - `popularity_bias(scores: np.ndarray, counts: np.ndarray, top: int = 20) -> dict`. Keys are `spearman`, `median_count_top`, `median_count_all`. `spearman` = Spearman correlation of `scores` vs `log(counts)`, computed with pandas.
  - `recall_at_k(scores: np.ndarray, positive: np.ndarray, k: int = 20) -> float`: the share of positives that appear in the top k.
  - `median_percentile(scores: np.ndarray, positive: np.ndarray) -> float`: the median over positives of `rank / n * 100`. Lower is better; 50 is chance. Positive-only: unlabeled items are never treated as negatives.
  - `match_known(known: list[str], candidates: list[str]) -> tuple[np.ndarray, list[str]]`. Returns a boolean positive mask over the candidates, plus the known tokens that are missing from the candidates.

from explorer import ranking as r

def test_unit_zero_row_is_zero_not_nan():
    out = r.unit(np.array([[3.0, 4.0], [0.0, 0.0]]))
    assert np.allclose(out[0], [0.6, 0.8]) and np.all(out[1] == 0)

    cand = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
    s = r.score(cand, np.array([1.0, 0.0]))
    assert list(r.ranks(s)) == [1, 3, 2]

def test_resolve_target_order():
    idx = {"MoS2": 0, "thermoelectric": 1, "chemical_vapor_deposition": 2}
    assert r.resolve_target("MoS2", idx) == "MoS2"
    assert r.resolve_target(" Thermoelectric ", idx) == "thermoelectric"
    assert r.resolve_target("Chemical  vapor deposition", idx) == "chemical_vapor_deposition"
    assert r.resolve_target("", idx) is None
    assert r.resolve_target("unobtainium", idx) is None

def test_context_words_top_k():
    vocab = np.array([[1.0, 0.0], [0.0, 1.0], [0.9, 0.1]])
    df = r.context_words(np.array([1.0, 0.0]), vocab, ["a", "b", "c"], np.array([0.0, 1.0]), k=2)
    assert list(df.token) == ["a", "c"] and list(df.columns) == ["token", "assoc", "target_cos"]

def test_popularity_bias_detects_frequency_ranking():
    counts = np.array([1, 10, 100, 1000])
    out = r.popularity_bias(np.log(counts), counts, top=2)
    assert np.isclose(out["spearman"], 1.0) and out["median_count_top"] == 550.0

def test_positive_only_metrics():
    s = np.array([0.9, 0.8, 0.1, 0.05]); pos = np.array([True, False, True, False])
    assert r.recall_at_k(s, pos, k=2) == 0.5
    assert r.median_percentile(s, pos) == 50.0   # ranks 1 and 3 of 4 -> 25%, 75% -> median 50

def test_match_known_reports_missing():
    mask, missing = r.match_known(["MoS2", "S2W", "XyZ9"], ["S2W", "MoS2", "Se2W"])
    assert list(mask) == [True, True, False] and missing == ["XyZ9"]

  - `pca(X: np.ndarray, n: int = 3) -> tuple[np.ndarray, np.ndarray]`: returns `(coords (len(X), n), explained_ratio (n,))`, computed with numpy SVD on the centered X.
  - `chemical_family(token: str) -> str`: first match in the order halide, telluride, selenide, sulfide, oxide, nitride, pnictide, carbide, other (spec 7b). Uses `pymatgen.core.Composition`.

1. **Literature set.**
